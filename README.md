# videos-hyperframes

Projets vidéo faits avec [HyperFrames](https://github.com/heygen-com/hyperframes) (HTML rendu en vidéo).

Les skills HyperFrames sont installées dans `.agents/skills/` et liées dans `.claude/skills/`, donc elles se chargent toutes seules dans une session Claude Code ouverte sur ce dépôt.

Un sous-dossier par vidéo, dans `videos/`.

Pour mettre les skills à jour :

```bash
npx skills update
```
